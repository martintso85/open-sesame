# 開盤密碼｜台股量化雷達

以 GitHub Pages 呈現、由 GitHub Actions 每日盤後自動更新的上市普通股量化雷達。

## 部署
1. 建立 GitHub repository。
2. 將本專案所有檔案上傳。
3. Settings → Pages → Source 選 GitHub Actions。
4. Actions 手動執行一次 `Daily Taiwan Stock Update`。
5. 之後平日每天自動更新。

## 功能
- **候選排序**:以單日漲幅百分比為主,再以成交金額與成交量排序,避免高價股因漲跌金額較大而長期壟斷技術分析名額。
- **互動篩選**:可搜尋股票代號/名稱,依優先觀察、量能放大、投信買超篩選,並切換訊號、漲幅、成交金額或投信排序。
- **⭐ 優先觀察訊號**:同時符合 ① 月線與週線趨勢向上 ② KD 黃金交叉 ③ 投信買超 ④ 大盤走勢轉強向上,清單以徽章明顯標示,並逐一顯示符合了哪幾項條件。
- **量增標示**:大盤成交值與個股成交量對比 5 日/20 日均量,量能明顯放大即標「量增」(不論當天漲跌)。
- **最新理由(做多誘因)**:個股近 20 日漲幅跑贏大盤時,自動帶出量化摘要(相對漲幅、投信買超、量能、KD、融資);新聞摘要欄位已預留,尚未接入來源前標示「資料待補」。
- **融資增減**:大盤融資餘額之當日增減與近 5 日趨勢;個股融資餘額單日增減幅明顯放大時標示「融資大增/大減」。
- **操作提示**:大盤趨勢向上時,順著 60 日均線(60K)操作;跌破 60K 時保守應對。

## 資料來源(TWSE 公開端點)
`STOCK_DAY_ALL`(盤後行情)、`T86`(投信買賣超)、`MI_MARGN`(融資融券餘額)、`FMTQIK`(大盤量值與指數)、`STOCK_DAY`(個股日K,預設前 30 名計算技術指標)。更新邏輯在 `scripts/update_data.py`,結果寫入 `data/dashboard.json`;任一來源暫時抓不到時,對應欄位標示「資料待補」,不影響其他欄位。

可用環境變數 `TOP_N`、`HISTORY_TOP`、`REQUEST_DELAY` 調整清單檔數、歷史分析檔數與 TWSE 請求間隔。工作流程設有 15 分鐘逾時，並會驗證 JSON 與執行單元測試後才提交資料。

本版本使用 TWSE 公開盤後資料;後續可擴充 TPEx、完整歷史K線與新聞摘要來源。
「優先觀察」只是量化篩選訊號,不保證獲利;任何勝率描述僅為歷史統計,不構成保證,也不是投資建議。
